电商多店 AI 连接器

让支持 MCP 的 AI 助手只读查询你自己店铺的经营数据，覆盖抖店、京东、淘宝、拼多多、快手、小红书、微信小店和巨量引擎 / 千川。

怎么用

  1. 下载 portable.zip 解压到路径里没有中文和空格的文件夹
  2. Windows 双击「启动（Windows 双击）.bat」；Mac 右键「启动（Mac 双击）.command」→「打开」
  3. 把窗口里打印的配置复制到 MCP 客户端配置文件，只保留要用的平台，填入自己的凭证后重启客户端
  4. 在客户端里直接提问，例如「读取抖店这个时间窗口的订单」
交付形式　MCP 服务（启动器 portable.zip），没有自己的界面；需自己在各平台申请凭证
